# 3D-Architectural-Design-CCTV-v1

昱拓弱電有限公司｜社區 B1 / B2 地下室 CCTV 3D 規劃網頁。

## 目前版本 V1.6
- B1 地下一層 / B2 地下二層兩個分頁
- PDF 平面圖轉成 3D 地板底圖
- Three.js 旋轉、縮放、平移、俯視
- 模組抽屜：牆體、柱子
- 牆體可調：長度 / 高度 / 厚度 / 角度
- 柱子可調：長度 / 寬度 / 高度 / 角度
- 鏡頭可移動，亦可勾選固定位置
- 七種鏡頭顏色分類：原建置紅、增設藍、故障橘；黃/綠/紫/灰可另命名
- 鏡頭焦距：2.8mm / 3.6mm / 4mm（預設） / 6mm / 8mm，並連動近似 FOV
- 網頁內專案資料夾：新增 / 儲存 / 讀取 / 刪除
- V1.6 新增「匯出專案檔」：支援瀏覽器檔案選擇器，可選電腦實際儲存位置；不支援時改為一般下載
- V1.6 新增「匯入專案檔」：可從 .utop3d / .json 恢復 B1/B2 鏡頭、模組與設定
- 每次版本更新：網頁可見版本、README、壓縮檔同步

## GitHub Pages 部署
把 `index.html`、`styles.css`、`app.js`、`assets/` 上傳到 repository 根目錄即可。
