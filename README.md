# 3D-Architectural-Design-CCTV-v1

昱拓弱電有限公司｜社區 B1 / B2 地下室 CCTV 3D 規劃網頁。

## 目前版本 V1.5
- 網頁標題顯示「昱拓弱電有限公司」
- B1 地下一層 / B2 地下二層兩個分頁
- Three.js 旋轉、縮放、平移、俯視
- 模組抽屜：牆體、柱子
- 牆體可調整：長度 / 高度 / 厚度 / 角度
- 柱子可調整：長度 / 寬度 / 高度 / 角度
- CCTV 鏡頭可移動、可勾選固定位置
- 七種鏡頭顏色：紅 / 藍 / 橘 / 黃 / 綠 / 紫 / 灰
- 顏色預設分類：原建置=紅、增設=藍、故障=橘；其他色可自訂名稱
- 鏡頭焦距：2.8mm / 3.6mm / 4mm / 6mm / 8mm
- 新增鏡頭預設 4mm
- 焦距選擇會自動帶入近似水平 FOV 與建議監看距離
  - 2.8mm：約 102°
  - 3.6mm：約 84°
  - 4mm：約 76°
  - 6mm：約 53°
  - 8mm：約 40°
- 專案儲存：新增資料夾、選擇儲存位置、儲存、讀取、刪除專案、刪除資料夾
- 專案儲存在瀏覽器 localStorage；同一瀏覽器可持續讀取
- 每次版本更新，README、壓縮檔與網頁可見版本號同步更新

> FOV 為常見監視器感光元件的近似值。實際可視角度會依感光元件尺寸、鏡頭設計與廠牌不同而略有差異。
