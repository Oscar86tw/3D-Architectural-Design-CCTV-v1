# 3D-Architectural-Design-CCTV-v1

昱拓弱電有限公司｜社區 B1 / B2 地下室 CCTV 3D 規劃網頁。

## 目前版本 V1.8

### 本版重點
- B1 / B2 兩個分頁
- 平面圖底圖保留原始長寬比例（2530 × 1980）
- X / Z 採同一縮放係數映射，角度判讀不失真
- 鏡頭可直接拖曳移動，勾選固定後不可再移動
- 柱子 / 牆體模組可直接拖曳移動，勾選固定後不可再移動
- 鏡頭焦距可選：2.8mm、3.6mm、4mm、6mm、8mm
- 鏡頭顏色可選：紅、藍、橘、黃、綠、紫、灰
- 顏色預設分類：原建置=紅、增設=藍、故障=橘
- 項目清單新增分類篩選，預設顯示「鏡頭」
- 牆體改為折線建立模式：連續點選多個點，按 Enter 完成，Esc 取消
- **新增鏡頭視角遮擋判斷**：若鏡頭前方有牆體或柱子，視角不會穿透，會依障礙物輪廓自動裁切為缺角形狀
- 可建立資料夾、選擇儲存位置、儲存 / 讀取 / 刪除專案
- 支援匯出 / 匯入 `.utop3d` / `.json`
- 每次更新同步更新網頁可見版本號、README 與壓縮檔版本號

## 比例說明
本版已確保底圖 X / Z 使用相同比例，鏡頭視角顯示不會因底圖拉伸而失真。
目前視角遮擋是以平面牆體與柱子外框作為遮擋模型進行計算，適合用來說明死角與增設鏡頭位置。
若後續要把監看距離精準對應實際現場公尺數，建議下一版再加入「兩點量測校正」功能，以已知尺寸進行實尺校正。
