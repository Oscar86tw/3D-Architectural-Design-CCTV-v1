# 3D-Architectural-Design-CCTV-v1

昱拓弱電有限公司｜社區 B1 / B2 地下室 CCTV 3D 規劃網頁。

## 目前版本 V1.10

### 本版更新
- 目前內建案場：**樺龍潮+ 社區**
  - B1 地下一層
  - B2 地下二層
- 鏡頭視角改為「實際可見範圍邊界」：
  - 不再鋪設彩色扇形面
  - 牆體或柱子會阻擋視線
  - 被遮住的方向不會穿透，外框會依實際可見範圍產生缺角
- 藍色鏡頭（增設）會在鏡頭上方顯示藍色提示氣球
  - 氣球中心高度依實尺比例設定為 **4 公尺**
- 新建牆體改為單一「連續牆體」模型：
  - 依序點選多個點
  - 點回第一個點（20px 範圍內）自動封閉並完成
  - 按 Enter 可完成未封閉的連續牆
  - 按 Esc 取消
  - 轉角採連續接合，不再顯示成一片一片 Box 拼接
- 連續牆體可整組拖曳移動，固定後不可拖曳
- 舊版單片牆體仍可正常讀取，避免既有專案資料失效
- 保留兩點實尺校正、焦距、7 色分類、鏡頭/模組拖曳與固定、社區/樓層管理、專案儲存/匯入/匯出功能

### 比例與可視範圍
- 圖面 X / Z 使用同一縮放係數，底圖不會被橫向或縱向拉伸。
- 兩點實尺校正後，鏡頭監看距離、牆體厚度、高度與 4m 提示氣球會使用相同的公尺換算比例。
- 視線遮擋目前以已建立的牆體 / 柱子模組為準；底圖上的線條本身不會自動成為遮擋物。
