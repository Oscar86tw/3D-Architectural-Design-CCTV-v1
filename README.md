# 3D-Architectural-Design-CCTV-v1

社區 B1 / B2 地下室 CCTV 3D 規劃網頁。

## 目前版本 V1
- B1 地下一層 / B2 地下二層兩個分頁
- PDF 平面圖轉成 3D 地板底圖
- Three.js 旋轉、縮放、平移、俯視
- 立體外牆輪廓開關
- 新增監視器位置
- 調整 FOV、監看距離、方向與備註
- 鏡頭資料儲存在瀏覽器 localStorage

## GitHub Pages 部署
把 `index.html`、`styles.css`、`app.js`、`assets/` 上傳到 repository 根目錄即可。
